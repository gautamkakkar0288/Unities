# 08 — Notifications (Screen)

## Purpose
Central inbox for relevant, non-spammy updates.

## Layout
Grouped list: Today / Yesterday / Older, each notification showing type icon, message, timestamp, unread indicator.

## Primary Action
Tap notification → deep link to relevant event/community/organizer.
Secondary: "Mark all as read."

## States
- Loading: skeleton list
- Empty: "You're all caught up." with a friendly illustration
- Error: "We couldn't load notifications." → Try Again
