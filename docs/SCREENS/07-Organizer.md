# 07 — Organizer (Profile)

## Purpose
Establish trust in the person/group hosting events.

## Content Order
Organizer header (name, verified badge, follower count) → Bio → Upcoming events → Past event history → Ratings/reviews → Follow CTA

## Primary Action
Follow Organizer (secondary: register for a listed event).

## Trust Elements
Verified badge is central to this screen — it's the core proof point of the Trust System.

## States
- Loading: skeleton header + event list
- Empty (new organizer, no events yet): "No events yet — check back soon."
- Error: "We couldn't load this organizer." → Try Again
