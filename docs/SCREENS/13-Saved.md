# 13 — Saved

## Purpose
Personal wishlist of saved events.

## Layout
List/grid of saved event cards, sorted by upcoming date by default.

## Primary Action
Tap a saved event → Event Detail screen.

## States
- Loading: skeleton grid
- Empty: "No saved events yet." → "Explore Events" button (per `DESIGN Bible` empty-state example)
- Error: "We couldn't load your saved events." → Try Again
