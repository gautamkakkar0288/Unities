# 11 — Onboarding

## Purpose
Get a new student to a personalized feed as fast as possible.

## Flow
Welcome → College selection → Interest selection (maps to communities) → Notification permission prompt → Land on personalized Home feed

## Primary Action
Continue / Get Started at each step.

## Principle
Minimal friction — every step should feel optional-but-encouraged, never blocking. Use illustrations (see `DESIGN/07-Illustration-System.md`) to keep tone friendly.

## States
- Loading: skeleton for college/interest lists as they load
- Error: "Something went wrong." → Try Again (never block the user from entering the app)
