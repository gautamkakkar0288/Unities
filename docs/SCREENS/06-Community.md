# 06 — Community

## Purpose
Long-term engagement hub around a shared interest (AI, Web Dev, Photography, Cricket, Gym, Dance, Music, Startups, etc).

## Content Order
Community header (name, member count, join CTA) → Description → Community feed/announcements → Upcoming events from this community → Members/moderators

## Primary Action
Join Community.

## States
- Loading: skeleton header + feed
- Empty (no activity yet): "This community is just getting started." → encourage first post/event
- Error: "We couldn't load this community." → Try Again
