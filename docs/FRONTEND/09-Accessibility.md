# 09 — Accessibility (Frontend Implementation)

## Mandatory Support (Every Component)
- Full keyboard operability
- Screen reader compatibility (semantic HTML, ARIA where needed)
- Visible focus states
- WCAG-compliant contrast
- Support for `prefers-reduced-motion`
- Touch targets sized appropriately (~44x44px minimum)

## Process
Accessibility is checked at both design review (`DESIGN/11-Accessibility.md`) and code review (`AI/Code-Review-Prompt.md`) — never treated as optional polish.
