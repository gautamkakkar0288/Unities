# 07 — Styling

## Rules
- Always use **Tailwind CSS**.
- Never use inline styles.
- Never use random/arbitrary spacing values.
- Never hardcode colors.
- Always reference design tokens (see `DESIGN/13-Design-Tokens.md`), implemented as Tailwind theme extensions.

## Consistency
Buttons, typography, spacing, cards, and navigation must look and behave identically across every screen — deviation requires a documented reason in `COMPONENTS/`.
