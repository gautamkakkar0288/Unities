# 11 — SEO

## Every Page Requires
- Title
- Description
- Open Graph tags
- Twitter Card tags
- Canonical URL
- Structured Data (planned for future — not MVP-blocking)

## Notes
Event, Organizer, and Community detail pages are the highest-value SEO surfaces (public, shareable, discoverable) and should be prioritized for complete metadata and, eventually, structured data (schema.org `Event`).
