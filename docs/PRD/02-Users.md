# Users & Personas

---

# Overview

Wonderer is designed for university students who want to make the most of their college life.

The platform serves multiple user groups, each with different goals and needs. Every feature should be evaluated based on how much value it creates for these users.

---

# Primary Users

## 🎓 Student

The primary user of Wonderer.

### Goals

- Discover events
- Find trips
- Join communities
- Learn new skills
- Meet new people
- Stay updated
- Build memories

### Pain Points

- Doesn't know what is happening.
- Misses registrations.
- Doesn't trust unknown organizers.
- Finds information scattered.
- Doesn't know which communities are active.

### Success

The student opens Wonderer daily and never feels like they're missing out.

---

## 🧑‍💼 Organizer

A club, student chapter, society, startup, or verified individual hosting activities.

### Goals

- Promote events
- Increase registrations
- Build trust
- Grow a community

### Pain Points

- Low visibility
- Repeatedly answering the same questions
- Managing registrations manually

### Success

Events reach the right audience with minimal effort.

---

## 👨‍💻 Administrator

Responsible for moderation and platform quality.

### Responsibilities

- Verify organizers
- Remove spam
- Review reports
- Moderate communities
- Feature important events
- Maintain platform quality

# User Motivations

Students join Wonderer because they want to:

- Explore campus life
- Meet new people
- Learn new skills
- Build memories
- Travel
- Network
- Improve resumes
- Have fun

---

# User Fears

- Fake organizers
- Losing money
- Missing registrations
- Low-quality events
- Wasting time

Wonderer must reduce these fears through verification, transparency, and reviews.

---

# Accessibility Goals

The platform should be usable by everyone.

Requirements

- Keyboard navigation
- Screen reader support
- High contrast
- Large touch targets
- Mobile-first design

---

# User Experience Principles

Every interaction should feel:

- Fast
- Friendly
- Predictable
- Premium
- Delightful

The platform should require as little effort as possible to discover opportunities.
