# Animations (Reference Notes)

## What Good Motion Looks Like Elsewhere
- Subtle card hover lift and shadow increase
- Smooth page/route transitions (fade + slight slide)
- Button press micro-feedback (scale down slightly on press)
- Pull-to-refresh with natural physics-based easing
- Toasts sliding in/out rather than appearing abruptly

## Application to Wonderer
All timing should stay within the 150–300ms window defined in `DESIGN/08-Motion-System.md` — reference products often use similar ranges for perceived responsiveness.
