# 05 — Notifications

## Notification Types
- Upcoming events
- Registration deadlines
- Community announcements
- Organizer updates
- Personalized recommendations

## Grouping
Grouped by: Today · Yesterday · Older, with an unread indicator and a "mark all as read" action.

## Principle
Quality over quantity — notifications should never feel spammy. Only notify users about relevant, personalized, and timely information (see `DESIGN Bible` — Notifications section).

## Delivery Channels
- In-app notification center (primary, MVP)
- Push notifications (future)
- Email digests (future)
