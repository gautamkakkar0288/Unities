# 07 — Illustration System

## Purpose
Illustrations are used primarily for:
- Empty states
- Error states
- Onboarding

## Style
Illustrations should be:
- Friendly
- Modern
- Minimal

They should reinforce Wonderer's warm, approachable brand — never generic clip-art, never overly corporate.

## Images vs Illustrations
- **Photos** should feel authentic, represent real students, and show genuine experiences — avoid generic stock photography.
- **Illustrations** are reserved for moments where no real photo exists (empty/error/onboarding states).

## Rules
- Maintain a single consistent illustration style across the entire app.
- Illustrations should never dominate a screen — they support a message, they don't replace it.
