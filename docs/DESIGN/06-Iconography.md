# 06 — Iconography

## Icon Library
Use **Lucide Icons** exclusively across the product. Never mix icon libraries.

## Rules
- Consistent size across contexts (define a small fixed set: e.g. 16px, 20px, 24px)
- Minimal, line-based style — matches Wonderer's clean visual language
- Meaningful — every icon must have clear semantic purpose
- Icons support text; they should rarely replace it entirely (exception: well-established nav icons like Home/Search/Profile)

## Usage Guidelines
- Pair icons with labels wherever meaning could be ambiguous
- Keep stroke width consistent across all icons in a view
- Use icon color to reinforce state (default, active, disabled, destructive) via design tokens, never hardcoded colors
- Avoid decorative or purely ornamental icon usage
